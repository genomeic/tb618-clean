# 双十一淘金币赛车任务 · 去助力版配置

iPhone 快捷指令「双十一淘金币赛车任务」的自用配置仓库，已移除作者的个人助力短链，
配置和 JS 改为从本仓库拉取，随时可以在网页上直接编辑。

## 文件说明

| 文件 | 作用 |
|---|---|
| `11.json` | 任务配置：菜单、任务列表、商品 ID、停留时间等 |
| `tb.txt` | 任务 JS：把配置展开成具体的链接播放列表 |
| `*.shortcut` | 快捷指令本体（每次运行从本仓库拉取上面两个文件） |

## 工作流程

1. 指令读取 `11.json` 的 `activity.list` 弹出菜单
2. 选择「开始1111任务」后读取 `taskData.赚话费.task`
3. 交给 `tb.txt` 的 `run()` 函数展开成 URL 列表
4. 依次打开每个链接并按 `wait` 停留对应秒数

## 如何修改任务（改完保存即生效，指令下次运行自动拉取）

- `activity.list` / `activity.mapping`：菜单项及对应链接或任务
- `taskData.赚话费.task.item`：商品 ID 列表，`占位参数1` 会被依次替换成这些 ID
- `taskData.赚话费.task.wait`：每个页面停留秒数
- `taskData.赚话费.task.before`：任务开始前先打开的链接
- `taskData.赚话费.task.param`：URL 里的关键词随机替换池

注意：`activity.vvv` 与指令内置的 `v` 是原作者留下的版本检测字段，已无作用，请勿修改。
